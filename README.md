# 📚 Interactive Storytelling Platform

A PHP-powered web application that lets users explore branching narratives through dynamic choices and immersive storytelling. Built with modular PHP scripts, a MySQL backend, and a clean HTML/CSS interface.

---

## 🚀 Features

- 🧩 Branching story logic with multiple paths and outcomes  
- 🗂️ Modular PHP files for story segments and user choices  
- 🛠️ MySQL database integration for story storage and user progress  
- 🎨 Custom CSS styling for visual storytelling  
- 🔐 Simple login system for personalized story sessions

## ✨ How It Works
- Users start at index.html and log in via login.php.
- Each story segment is handled by a dedicated PHP file.
- Choices made by the user trigger different scripts (left_tree.php, right_tree.php, etc.).
- The database tracks user progress and story branches.
